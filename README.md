## Structure

```
index.html                Home page
privacy.html              Privacy Policy
cookies.html              Cookie Policy
terms.html                Terms & Conditions
dpa.html                  Data Processing Agreement summary
complaints.html           Complaints procedure
404.html                  Page not found
assets/css/style.css      All styling
assets/js/main.js         Menu, daily shift report, Web3Forms enquiry form
assets/img/               Monitoring photo and favicon
site.webmanifest          Browser app details
robots.txt                Search engine rules
.well-known/security.txt  Security contact
.nojekyll                 Serve files as they are on GitHub Pages
LICENSE, .gitignore
```

## Publishing on GitHub Pages

1. Create a repository and upload everything in this folder to the root, including the hidden files (`.nojekyll`, `.well-known`, `.gitignore`).
2. Go to **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. For a custom domain, add it under **Settings > Pages**. GitHub then creates a `CNAME` file.

## Before launch

- Have a solicitor review the legal pages (privacy, cookies, terms, DPA, complaints).
- Add a `sitemap.xml` and a `Sitemap:` line in `robots.txt` once the domain is final.
- The enquiry form uses Web3Forms (`access_key` in `index.html`). Mail goes to the address verified in the Web3Forms dashboard.
- The daily shift report on the home page is generated by `assets/js/main.js`. It is not live call data.
- If you add analytics or marketing cookies later, add a consent banner and update `cookies.html`.
