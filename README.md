# Orbio Desk website

Static, mobile-first website for Orbio Desk (24/7 dispatch and call handling for UK executive, chauffeur and private hire firms), a brand of Orbio Ltd.

- Registered office: 2 Frederick Street, Kings Cross, London WC1X 0ND

## Structure

```
index.html                Home page (SEO title, description and Schema.org JSON-LD included)
operator-samples.html  Operator call recordings page (not indexed by search engines)
privacy.html cookies.html terms.html dpa.html complaints.html   Legal pages
404.html                  Page not found
assets/css/style.css      All styling
assets/js/main.js         Menu, daily shift report, sticky CTA, exit-intent popup, Web3Forms form
assets/card/index.html  Interactive digital business card (opens in a pop-up from the home page)
assets/img/               Monitoring photo (lazy loaded) and favicon
assets/audio/   Three call samples (booking-sample-01 to 03, .mp3)
sitemap.xml, site.webmanifest, robots.txt, .well-known/security.txt, .nojekyll, LICENSE, .gitignore
```

## Publishing on GitHub Pages

1. Upload everything in this folder to the repository root, including hidden files (`.nojekyll`, `.well-known`, `.gitignore`).
2. **Settings > Pages**: Deploy from a branch, `main`, `/ (root)`.
3. Custom domain: add it under **Settings > Pages** (GitHub creates a `CNAME` file).

## Before launch

- Have a solicitor review the legal pages and the "No Missed Booking Guarantee" wording.
- The canonical URL, social tags, JSON-LD `url`, `sitemap.xml`, `robots.txt` and the link in `404.html` use https://abdullahrehan849.github.io/orbio-desk/. If you move to a custom domain, replace that address in those files.
- The enquiry form uses Web3Forms (`access_key` in `index.html`). It will not send from the Claude preview, only from a real website.
- The daily shift report is generated by `assets/js/main.js`. It is not live call data.
