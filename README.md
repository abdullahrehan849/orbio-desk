## Publishing on GitHub Pages

1. Create a repository and upload all the files from this folder (including `.nojekyll`) to the root.
2. Open **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. For a custom domain, add it under **Settings > Pages > Custom domain**. GitHub then creates a `CNAME` file for you.

## Enquiry form

The Send Proposal form uses Web3Forms and submits on the same page. Messages are delivered to the email address verified against the access key in `index.html` (`access_key` hidden field). To change the recipient, change it in the Web3Forms dashboard.
